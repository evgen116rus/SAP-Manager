# Список изменений SAP Manager

Изменения перечислены от начала разработки к последним.

## 1. Первая версия (консольная)
- Программа на C++ на основе `sap_install.cmd`, `sap_uninstall.cmd`, `SAP_Crypto_Copy.cmd`, `saplogon_options.reg` и `saplogon_options_HKCU.reg`.
- Интерактивный ввод имени удалённого компьютера.
- Все удалённые команды выполняются через `pse.exe` с ключом `-r ps_sap`.
- Проверка, установлен ли SAP GUI: наличие и версия `saplogon.exe`, наличие деинсталлятора, разрядность ОС.
- Проверка компонентов SAP Crypto (`sapcrypto.dll`, `sapgenpse.exe`, `slcryptokernel.dll`, `ssfrfc.ini`): на месте, отсутствует или отличается по размеру от эталона. Копирование через админ-шару `C$`.
- Установка и удаление SAP GUI, PDF Print GUI, Business Explorer и Secure Login Client по шагам из ваших cmd-скриптов.
- Reg-файл применяется в реестр вошедшего пользователя: определяется пользователь и его SID, `HKEY_CURRENT_USER` заменяется на `HKEY_USERS\<SID>`, импорт выполняется через `pse.exe` и `reg import`.
- Служба «Удалённый реестр» переводится в «Автоматически» и запускается.
- Сборка на GitHub Actions (MSVC, x64): `build.yml`.

## 2. Исправление сборки
- Шаг сборки больше не падает, если reg-файлов нет в репозитории (`if exist`), ошибка компиляции по-прежнему останавливает сборку.

## 3. Выбор компонентов установки
- Установка с выбором компонентов: SAP GUI, PDF Print GUI, Business Explorer, Secure Login Client, SAP Crypto, `set_xml_path.reg`, настройки SAP Logon.

## 4. Оконный интерфейс
- Консоль заменена на окно Win32: поля компьютера, учётной записи и пароля, флажки компонентов, кнопки действий, журнал.
- Операции выполняются в фоновом потоке, окно не зависает. Вывод `pse.exe` попадает в журнал.
- Подтверждения выводятся обычными окнами Да/Нет.
- В `build.yml` добавлен ключ `/SUBSYSTEM:WINDOWS`.
- Добавлен `README.md`.

## 5. Исправление `set_xml_path.reg`
- Файл раньше применялся командой `regedit /S` от SYSTEM, из-за чего пути XML попадали не в реестр вошедшего пользователя. Теперь он применяется тем же способом, что и `saplogon_options.reg` (через SID).
- После импорта проверяется наличие первого ключа файла в `HKEY_USERS\<SID>`.
- Кнопка «Reg пользователю» применяет оба reg-файла.

## 6. Диагностика ошибки доступа к `\\ПК\C$`
- В журнал выводятся код ошибки Windows, её текст и подсказка по причине (коды 5, 53, 67, 1326, 1219).
- При указанной учётке подключение выполняется прямо к `\\ПК\C$`.
- В `README.md` добавлена таблица кодов.

## 7. Диагностика сети
- Перед подключением выводится точное имя и его длина, лишние символы в имени вырезаются.
- При ошибке выводятся IP-адреса имени, обратные имена и состояние порта 445.
- Если порт 445 открыт, делается попытка подключиться по IP-адресу.

## 8. Кодировка вывода и режим запуска процесса
- Исправлена кодировка вывода `pse.exe` (автоматический выбор между ANSI и OEM).
- Добавлен флажок «Процесс на ПК от указанной учётки (иначе SYSTEM)». По умолчанию учётка используется только для подключения, а процесс запускается от SYSTEM.
- При ошибке 1385 («режим входа не предусмотрен») показывается подсказка.

## 9. Локальный режим и пути в ini
- Если имя компьютера не указано, установка, проверка, удаление и применение reg выполняются на этом ПК без `pse.exe`.
- Пути к файлам установки вынесены в поля окна и в файл `sap_manager.ini` рядом с программой. Рядом с каждым компонентом добавлена кнопка «...» с окном «Обзор...» (папка или reg-файл).
- Окно увеличено по высоте.

## 10. Служба «Удалённый реестр»
- Служба запускается только в начале установки и проверки («Статус») и только для удалённого ПК. В локальном режиме она не запускается и не меняется.
- Кнопка «Reg пользователю» службу не запускает: если она остановлена, проверка ключей после импорта пропускается с предупреждением.
